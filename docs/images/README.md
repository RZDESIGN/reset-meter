# Preview image provenance

The PNG previews in this directory are rendered directly from Reset Meter's SwiftUI views with synthetic demo usage. They contain no live provider responses, account identifiers, personal paths, or desktop capture.

Regenerate both previews from source:

```sh
./scripts/generate-previews.sh
```

This creates `reset-meter.png` and `reset-meter-menu.png` at 2× scale.
